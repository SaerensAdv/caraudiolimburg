1) Tech stack (monorepo)
	•	Framework: Next.js 14 (App Router) + TypeScript
	•	UI: Tailwind CSS + shadcn/ui componenten (Cards, Tables, Dialogs, Forms, Toaster) + lucide-react icons
	•	State/Forms/Val: React Hook Form + Zod schema’s (validatie + types)
	•	DB & ORM: PostgreSQL (Neon of Supabase) + Drizzle ORM + drizzle-kit (migraties)
	•	Auth: Auth.js (Credentials/Email providers) + session via JWT; roles via RBAC (Owner, Staff, Installer, Customer)
	•	API: Next.js Route Handlers (REST) met Zod-validated DTO’s
	•	E-mail: Resend (transactionele e-mails)
	•	Betaling: Stripe (Cards, Bancontact, iDEAL, Apple Pay/Google Pay) + Webhooks
	•	Bestanden/afbeeldingen: public/ + optioneel UploadThing + S3/R2 (feature flag)
	•	Zoek/filters: Postgres Full‑Text Search + faceted filters
	•	Caching/Rate limiting: In‑app cache + simple rate limit (IP + token bucket). Optioneel Upstash Redis (feature flag)
	•	Tests: Vitest (unit), Playwright (E2E basis), Drizzle migratie test
	•	Lint/Format: ESLint + Prettier + strict TS config
	•	i18n: NL als default, structuur klaar voor EN (next-intl)
	•	Analytics: Plaats voor GA4 + server events (consent‑aware)
	•	DevOps (Replit): NPM scripts + .replit/replit.nix + .env (Secrets in Replit)

Fallback-stijl (als caraudiolimburg.shop niet te lezen is): Donker thema, accentkleur #00E0A4 (teal/mint), secundair #111827; Sans-serif (Inter/Plus Jakarta Sans), grote productfoto’s, cards met zachte shadow en afgeronde hoeken (rounded-2xl), focus op voertuigfilters en installatie CTA’s.

5) Belangrijke user flows (acceptatiecriteria)
	1.	Product kopen zonder installatie → winkelwagen → Stripe kaart/Bancontact/iDEAL → bevestiging → e-mail met order.
	2.	Product + installatie → productpagina: selecteer “met installatie” → kalender/slot → in checkout zichtbaar → bevestiging → e‑mail met order + ICS bijlage.
	3.	Alleen installatie boeken (service) → kies voertuig → kies slot → betaal (aanbetaling of totaal) → e‑mail + ICS.
	4.	Offerte aanvragen (lead) → wizard + uploads → CRM kaart “Nieuw” → e‑mail naar staff + bevestiging naar klant → admin kan offerte genereren + verzenden (pdf/email) → klant accepteert via link → lead → order.
	5.	Admin kan: producten CRUD, voorraad updaten, fitments beheren; leads stages drag&drop; slots beheren; refunds doen; content publiceren; gebruikers en rollen beheren.
	6.	SEO: product/categorie/service/blog met juiste meta, OG, schema, sitemap, breadcrumbs.

6) Integraties & implementatie-details

	•	Activeer Bancontact en iDEAL.
	•	Betaalflow:
	•	server‑route POST /api/checkout → PaymentIntent met line items;
	•	success/cancel pages;
	•	webhook /api/stripe/webhook verwerkt payment_intent.succeeded/failed, maakt/actualiseert Order.
	•	Refund endpoint in admin orderdetail.

	•	Templates: Orderbevestiging, Offerte verzonden, Offerte geaccepteerd/afgewezen, Installatiebevestiging (met ICS), Afspraakherinnering (24u vooraf).

	•	Genereer .ics met titel “Installatie – {product/service} – {naam}”, locatie (werkplaatsadres), start/eindtijd, beschrijving en ordernummer. Voeg bij in e-mail + download in account.

6.4 Vehicle fitment
	•	Admin UI: voeg vehicles toe; koppel via Fitments aan producten; front-end filtert automatisch op gekozen voertuig.

6.5 Leads/CRM
	•	Kanban UI (shadcn DnD). Lead detail met notities, bijlagen, activiteitenlog.
	•	Offerte: editor (items, arbeid, uren, korting, BTW) → render PDF → e‑mail link (publieke view met accept/decline + digitale handtekening naam + checkbox akkoord voorwaarden).
	•	(Optioneel) Webhook/Export naar ClickUp via env-flag.
