# Visual Prompt Framework - Car Audio Limburg

## Bedrijfscontext

**Bedrijf**: Car Audio Limburg - Premium car audio specialist  
**Locatie**: Sittard, Limburg  
**USP's**:
- 25+ jaar vakmanschap
- Premium merken (Alpine, Audison, Hertz, BlackVue)
- Fabriekskwaliteit installaties
- Persoonlijk advies in showroom
- 2 jaar garantie

**Doelgroep**: Autoliefhebbers (25-55 jaar) die waarde hechten aan kwaliteit, BMW/VW/Audi rijders, mensen die hun rijervaring willen upgraden

**Branding**:
- Primaire kleur: Goud #D0A760
- Accent: Crème #F6EDDF
- Achtergrond: Zwart/Donkergrijs
- Stijl: Premium, professioneel, warm

## 5. A/B Test Suggesties

### Test 1: Kleur Warmte
- **Variant A**: Koud (grafiet/zilver) - professioneel, technisch
- **Variant B**: Warm (zwart/goud) - premium, emotioneel
- **Meet**: Click-through rate, engagement

### Test 2: Mens vs Product
- **Variant A**: Pure productfoto (speaker alleen)
- **Variant B**: Product in gebruik (installatie door vakman)
- **Meet**: Conversie, time on page

### Test 3: Setting
- **Variant A**: Studio (clean, gefocust)
- **Variant B**: Werkplaats (authentiek, vertrouwen)
- **Meet**: Trust signals, quote requests

### Test 4: Emotie vs Informatie
- **Variant A**: Lifestyle (rijplezier, vrijheid)
- **Variant B**: Technisch (specs, vergelijking)
- **Meet**: Target audience response

### Test 5: Seizoensgebonden
- **Variant A**: Evergreen (geen seizoen)
- **Variant B**: Seizoensspecifiek (zomer/winter)
- **Meet**: Relevantie, urgentie conversie

## 7. Negatieve Prompts (Wat te vermijden)

Voeg deze toe aan je prompts om ongewenste elementen te vermijden:

```
Negative prompt: cartoon, illustration, anime, 3d render, CGI, watermark, 
text overlay, logo, blurry, low quality, oversaturated, unrealistic colors, 
stock photo feel, generic, cheesy, outdated design, messy background, 
cluttered, amateur photography, harsh shadows, overexposed
```

## 8. Consistentie Checklist

Voordat je een afbeelding gebruikt, check:

- [ ] Kleurpallet matcht brand (zwart/goud/crème)
- [ ] Kwaliteit is hoog genoeg (min 1080p)
- [ ] Geen concurrerende logo's zichtbaar
- [ ] Past bij de boodschap/context
- [ ] Emotie komt overeen met doel
- [ ] Formaat klopt voor platform
- [ ] Consistent met andere recente content
